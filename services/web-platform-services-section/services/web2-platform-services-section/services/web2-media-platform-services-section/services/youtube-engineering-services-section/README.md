# YouTube engineering

The YouTube adapter exposes identity verification, upload inventory, cheap batched video-stat snapshots, targeted owner Analytics reports, resumable video upload, thumbnail upload, and publication scheduling. Import `createYouTube` from `@emsenn/youtube-engineering-services-section/api` with an explicit channel ID, credential environment, fetch implementation, and effect-authorization callback. Uploads require a stable marker and a durable private checkpoint callback; a resumed upload must retain its original bytes and publication time. `batchVideoStats` reads current public/owned counters and duration facts through `videos.batchGetStats`; `analyticsReport` runs channel-bound targeted queries while leaving timestamped storage and interpretation to the consuming service.

`@emsenn/youtube-engineering-services-section/authorize` connects a channel by OAuth with PKCE. `consentRequest` makes the Google consent link for a loopback redirect, `returnedConsent` reads the code from the address Google sends the browser back to (a request URL, or an address pasted from a browser that could not load it), and `exchangeConsent` trades the code for a refresh token, kept only once it identifies the configured channel. `authorizeYouTube` runs all three behind a loopback server on the machine whose browser gives consent; a person signed in elsewhere pastes the returned address instead.

`@emsenn/youtube-engineering-services-section/credentials` is the node's one home for YouTube credentials, `$XDG_CONFIG_HOME/561-group/youtube.env` (owner-only, or `YOUTUBE_CREDENTIALS`): the shared OAuth client as `YOUTUBE_OAUTH_CLIENT_ID` and `YOUTUBE_OAUTH_CLIENT_SECRET`, and each channel's refresh token under the name its channel config declares. `readYouTubeCredentials` reads it and `retainYouTubeCredential` replaces one name atomically.

[Public education](../../../../../../../../../../../../../../../public-services-section/services/public-social-services-section/services/public-education-services-section/README.md) owns the channel CLI, curricula, editorial decisions, research/video composition, state, and production timer. Research, Gemini Notebook rendering, image generation, transcription, and media conversion are upstream capabilities consumed there. This adapter has no knowledge of education directories or lesson records.

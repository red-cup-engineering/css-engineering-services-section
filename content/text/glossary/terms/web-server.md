The web-server is a web server. It answers requests. [TUFTE](tufte.md) is the web app framework, and VICTOR publishes content as TUFTE-rendered HTML with no server. All three are designed around the [Semiotic Hypertext Packet](semiotic-hypertext-packet.md), which is downstream of SignStuff. See the note `2026-09-29-note-on-the-web-server-tufte-and-victor-stack.md` in this section.

## Algorithm and authority invariants

Process configured descriptors in declaration order, one observation per source. Retain failed coverage before processing healthy siblings. Admit successful complete observations only when source identity and freshness agree; reject malformed payload atomically per source. Filter source-listed public rows; preserve original row order. Search is case-insensitive substring over original title/description/id and declared keywords, with exact source filter using shared TUFTE filtering; no model inference or new economic ranking. Detail/selection uses the pair (sourceId,originalId), never title equality. Same edition may be disclosed, but different source row identity and rail remain distinct.

Comparison is side-by-side, not an automatic winner: priceComparable requires every selected item have a fixed valid integer quote with the same asset, network, unit, and same declared operation/outcome identity; absent comparability returns false and an explicit reason. If comparable, do not change the original values or add FX; show exact source terms. No default source ownership boost, paid placement, quantity arithmetic, budget debit, endorsement or commercial contract occurs.

Every fetch is exactly the configured GET URL with no user credentials, wallet headers or user query appended. Use binding.fetch(new Request(source.url,{method:'GET',redirect:'manual'})) when the descriptor names an existing env service binding; otherwise fetchImpl with redirect:'manual'. Reject any redirect/402/non-success, unsupported MIME, over-budget stream or invalid JSON as a source-local refusal. Streaming byte limit is enforced before JSON parsing. SHA-256 digests use the runtime cryptographic primitive over exact complete bytes. Timeout aborts only that read; no automatic retry of a payment or source request. Configuration fixes finite limits; initial proposed bounds are 1048576 bytes/source and 8000 ms/source, based on the observed MPP body of 578531 bytes, not capacity reservations. All sources can be fetched concurrently; no output list is considered complete if a source was cut off.

No persistent cache is needed initially. In-request observations feed every representation of that request; no list import becomes a second mutable catalog. Optional future cache must be keyed by descriptor/consent revision and expose age; revoked/changed descriptors invalidate cached visibility. Loss of ephemeral observations loses no merchant data or accepted Work. No new R2/KV/DO is required for navigation. Durable source/fabrication/bundle/installation provenance remains with the existing release owner; root obtains fresh storage/capacity admission before materialization.

## Data contracts

Configuration: role is bazaar or market; origin is canonical HTTPS without credentials/query/fragment; title is presentation text; revision is source-selected immutable identity; sources is a list of unique descriptors. Descriptor: {id,kind,url,publisher,consent,maxAgeSeconds,maxBytes,timeoutMs,binding?}. kind is shop-catalog, x402-catalog, index-health, mpp-catalog or bazaar-summary. consent is {status,evidence,revision,expiresAt}; status is house-publication, seller-consented, public-market-observation, unverified or revoked. evidence/revision may be null only for unverified/revoked; expiration null means the particular house/public observation authorization has no asserted expiry. A supplied external seller-consented descriptor requires original seller evidence and cannot be fabricated from a reachable feed. Host configuration admission rejects private/local IP literals, credentials, fragments, non-HTTPS, duplicate source IDs, unsupported kinds, invalid expiry and nonpositive/nonfinite bounds. Configuration is never merged with request input.

Observation: {sourceId,url,observedAt,sourceDate,digest,status,body,error}. status is ok, unavailable, invalid or incomplete. digest is sha256:<lowercase exact response-byte digest> for complete successful bytes, otherwise null. body is the original parsed public JSON or null. sourceDate is the publisher's actual supplied date or null; fetch time is not relabeled source time. error is a bounded public explanation, never tokens, headers or private body. Future, stale, unknown, incomplete, malformed or source-URL-mismatched observations do not supply current offers. They remain source coverage entries.

Pure input: {role,origin,revision,now,query,sources,observations}. query is {q,source,selected}; source is source ID or null; selected is a list of {sourceId,id} references. Default query is empty, no selected references. The host supplies now and observations; the public only controls q, source and selected references. Wrong role/origin/configuration or malformed/duplicate query produces a TypeError before the live adapter fetches.

Pure output: {role,origin,revision,coverage,items,comparison,venues,limitations}. coverage retains each configured source's {sourceId,url,status,observedAt,sourceDate,digest,reason}; status is current, stale, unavailable, refused or incomplete. items contains Bazaar results only, venues Market results only; other role's list is empty. comparison is null without selection; otherwise {items,priceComparable,reason}, with original selected items and explicit incompatible/missing-terms reasoning. limitations is an ordered list of plain source-scope statements, including house-only coverage and unreceived independent seller/transaction qualification. Missing requested selected identity is an explicit not-found result from the HTTP/tool layer; never select another offer by title.

Bazaar item: {sourceId,id,publisher,seller,title,description,url,protocol,status,edition,price,qualification,original}. id is the original source product ID or original x402 SKU; seller is the exact declared original seller or null. publisher is the admitted source descriptor; this does not fill a missing seller. edition is original book edition digest or x402 compute.configuration.release, otherwise null. price is {amount,asset,network,unit} with exact integer amount string when source supports it, otherwise null. original is the original already-public offering row with no invented fields. qualification is source-listed unless a separate original qualification object is actually supplied and received; it is never verified because a URL responds. Shop row url is canonical source origin + /goods/ + encodeURIComponent(original id), protocol is shop, status preserves live/coming-soon; currency minor units are represented as asset original currency and unit minor-currency-per-edition, network null. x402 row url/method/SKU and current network/asset atomic amount are retained exactly; price unit is atomic-asset-per-original-operation; listed:false is excluded. Unknown price, non-fixed tariff, missing seller, hidden/private source and nonpositive malformed integer amount do not become a guessed fixed price. Every actionable item url must independently admit direct HTTPS, without credentials, fragment, localhost/single-label/local/private/special-use host or private/special-use IP literal. Unsafe original URLs remain unchanged only inside original; normalized item url is null and the UI action is unavailable, never an active href. Do not fetch item action URLs. Source-listed inspection may remain visible without a purchase action.

Market venue: {sourceId,publisher,url,observedAt,sourceDate,digest,kind,metrics,limitations}. Metrics are {name,value,unit,population,method,sourceField}; economic metrics unsupported by the source remain null. index-health maps only original total_endpoints, distinct_services, distinct_providers, by_protocol and by_health with publisher-reported scope; MPP counts services.length and the sum of declared endpoints.length in a complete fetched catalog; these are catalog-entry/declared-endpoint counts, not independent actors, signed payments or useful deliveries. Bazaar summary counts actual projected items/source surfaces and says independent seller count unknown. Never sum external venue populations.

## Algorithm and authority invariants

Process configured descriptors in declaration order, one observation per source. Retain failed coverage before processing healthy siblings. Admit successful complete observations only when source identity and freshness agree; reject malformed payload atomically per source. Filter source-listed public rows; preserve original row order. Search is case-insensitive substring over original title/description/id and declared keywords, with exact source filter using shared TUFTE filtering; no model inference or new economic ranking. Detail/selection uses the pair (sourceId,originalId), never title equality. Same edition may be disclosed, but different source row identity and rail remain distinct.

Comparison is side-by-side, not an automatic winner: priceComparable requires every selected item have a fixed valid integer quote with the same asset, network, unit, and same declared operation/outcome identity; absent comparability returns false and an explicit reason. If comparable, do not change the original values or add FX; show exact source terms. No default source ownership boost, paid placement, quantity arithmetic, budget debit, endorsement or commercial contract occurs.

Every fetch is exactly the configured GET URL with no user credentials, wallet headers or user query appended. Use binding.fetch(new Request(source.url,{method:'GET',redirect:'manual'})) when the descriptor names an existing env service binding; otherwise fetchImpl with redirect:'manual'. Reject any redirect/402/non-success, unsupported MIME, over-budget stream or invalid JSON as a source-local refusal. Streaming byte limit is enforced before JSON parsing. SHA-256 digests use the runtime cryptographic primitive over exact complete bytes. Timeout aborts only that read; no automatic retry of a payment or source request. Configuration fixes finite limits; initial proposed bounds are 1048576 bytes/source and 8000 ms/source, based on the observed MPP body of 578531 bytes, not capacity reservations. All sources can be fetched concurrently; no output list is considered complete if a source was cut off.

No persistent cache is needed initially. In-request observations feed every representation of that request; no list import becomes a second mutable catalog. Optional future cache must be keyed by descriptor/consent revision and expose age; revoked/changed descriptors invalidate cached visibility. Loss of ephemeral observations loses no merchant data or accepted Work. No new R2/KV/DO is required for navigation. Durable source/fabrication/bundle/installation provenance remains with the existing release owner; root obtains fresh storage/capacity admission before materialization.

## HTTP and MCP mapping

Bazaar GET/HEAD / renders TUFTE search results and source coverage; /offers uses one source/id pair; /compare uses matched repeated source/id pairs. /discovery.json lists role, canonical origin, revision, source scope and exact free endpoint/tool links; /v1/discovery/search and /v1/discovery/compare return the same pure projection/results. POST /mcp mounts search_offers({q?,source?}), get_offer({source,id}), compare_offers({selected:[{sourceId,id}]}). Unknown fields, incomplete pairs and duplicate singleton parameters refuse 400; missing selected ID returns 404. Public q is bounded to 256 characters and selection to eight references; these are configured technical limits, not claims of optimum workload. GET/HEAD only for data/HTML; other methods 405, unknown path 404. HEAD uses corresponding headers/status without a body. Source directory can return 200 without live data; data search/readout with all configured sources unavailable returns 503; partial availability returns 200 with explicit coverage.

Market handles exactly /, /markets/discovery.json, /markets/observations, /markets/venues and /markets/mcp. Its MCP tools are list_markets({}), read_observations({source?}). All other requests go immediately to env.MERCHANT.fetch(originalRequest) before reading body or parsing the URL beyond exact routing. The original /mcp, /v1/*, /actors/*, /.well-known/*, settlement/recovery headers and raw signed bodies are neither interpreted nor rebuilt. Return the actual binding Response object unchanged. Missing required binding yields 503 for the forwarding branch, never a fallback copy. The generic generated default Worker entry reads only env.COMMERCE_CONFIGURATION as host configuration, selects configuration only by canonical request host and calls createCommerceNavigator; unknown host refuses 421 before sources. Bazaar has no merchant fallback and never serves original payable routes.

## V-model assays and receiving

Source contract assays: accepted two house catalogs retain all original identity/edition/source status; alternate q/source changes results without altering source order; unverified external consent, revoked consent, stale/future clock, malformed price, URL drift and incomplete body refuse their current records. A same-title and same-edition alternate with incompatible rails stays distinct and noncomparable. Same asset/network/unit without the same declared original outcome also remains noncomparable. Fixtures cannot establish independent seller consent or received sale.

Component assays: native TUFTE renders both roles, escapes script-shaped source titles, rejects unsafe action schemes/credential/private/local hosts as active hrefs while retaining inert original evidence, has working URL search/detail/back links and original direct seller actions; MCP initialize/tools/list/tools/call and HTTP produce the same original records; fake source fetch observes only allowlisted configured GETs and no user credential forwarding; all-source/partial outage status is honest. Native test-only fake fetch and clock are host supplied, never request fields.

Preservation assays: send signed-like binary/non-UTF8 POST bytes, payment and recovery headers, cookies, query order and canonical market URL to a fake merchant binding; assert same original Request identity at binding, one fetch, and same returned Response identity/headers/body. Test /mcp and original /v1/publications resource dispatch; root route and exact Market discovery do not reach merchant. Bazaar payable paths refuse. Probe live original catalog/Shop goods/unsigned x402 challenge before and after rollout; do not pay. Freeze original merchant deployment identifier and Shop catalog/accepted artifact fingerprints.

Independent receiving: use exact built module/source/dependency digests, qualified native proposal, actual test results, esbuild/Worker manifest, service binding, DNS/TLS and installed release evidence. Verify a real human title search/detail/compare and real read-only MCP call, plus both original external Market observations with source times/units and uncertainties. Keep unseen cases with the receiver, including factory/default Worker HTTP/MCP behavior, unsafe item action URLs and same-price different-outcome comparison; five pure-generation examples are not whole-system receiving. A failed or malformed derivation returns its actual phase/refusal to the original Work; it is not repaired by hand or declared complete from a plan.

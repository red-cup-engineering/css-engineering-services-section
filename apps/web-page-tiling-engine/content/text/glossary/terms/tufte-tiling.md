TUFTE tiling is the partition and composition of browser application surfaces
without overlap becoming the default means of organization. It includes
semantic placement, user move and resize operations, nesting, responsive
constraints, and persistence. The current twelve-track CSS grid and authored
tile order are the first renderer and data source for tiling; they are not the
complete capability. Tiling participates in the wider
[TUFTE framework charter](../../documents/articles/notes/2026/08/30/2026-08-30-note-on-tufte-framework-charter.md).

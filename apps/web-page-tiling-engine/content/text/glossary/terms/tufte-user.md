A TUFTE user is a human participant whose perception, focus, actions,
preferences, accessibility needs, arrangements, and undoable choices are part
of the application model. “User” rules out treating an interface as only a
document delivered to a passive reader. This specialized meaning is governed
by the [TUFTE framework charter](../../documents/articles/notes/2026/08/30/2026-08-30-note-on-tufte-framework-charter.md).
